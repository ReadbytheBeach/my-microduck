# Session 01 · MicroDuck 电子皮肤部署与商业分析

> 主题：在 Pollen Robotics MicroDuck 上部署 4 块 12×12 压阻电子皮肤的技术可行性（电气 / 软件 / 机械全链路），及其商业价值与受众分析；附 Ω 形服务环工程答疑。
> 存档日期：2026-09-03

---

## 1. 硬件基线：鸭子身上到底有什么可挂的？

**结论**：MicroDuck 没有任何能直接"透传"第三方传感器的高速接口，但舵机总线和 HAT 的 Stemma I2C 留下了两条合规的挂载路径。全部事实经官网与 GitHub 仓库遍历核实：

- 主控：**Radxa Zero 3W**（RK3566，4×Cortex-A55，0.8 TOPS NPU，1GB RAM，Armbian）
- 舵机：15× Dynamixel **XL330**，Protocol V2，**TTL 半双工 3.3V @ 1Mbps**，走 UART2（/dev/ttyS2）
- 总线拓扑：单总线 16 设备——右腿 10–14、左腿 20–24、颈/头/嘴 30–34，另有官方 **imu_to_dxl 从机 ID 200**（关键先例：官方自己就往总线上挂非舵机设备）
- 总线余量：50Hz 控制环下 tick 占用约 25%
- 电源：NP-F550 2S 电池 6.6–8.2V **直驱舵机**（无稳压）；HAT 上 AP63205  buck 出 5V
- HAT 扩展：TLV320AIC3104 音频 + **Stemma J5（I2C 400kHz）**，已挂 ToF（0x29）
- 结构：头部空腔约 92×123×46mm（约 490cm³，4-DOF 颈部，head_yaw ±170°）；足底为独立可拆件 41×54×13mm（STL 已开源 CC BY-SA-NC）
- 软件：纯 Rust 运行时（robotd / updaterd / configd / btd / padd / mediad / tofd，JSON-RPC over Unix socket），**无 ROS**；50Hz ONNX 策略推理

## 2. 最终方案：4×12×12 皮肤怎么挂上去？

**结论**：皮肤原始数据流不进任何现有接口，正确模式是"**本地数字化 + 特征上传**"——前端扫描芯片把 144 个 taxel 压成 12B 特征包，由 skin_hub 仿官方 IMU 先例挂总线。

- 传感规格：4 块 12×12=144 taxel 压阻皮肤（头左/头右 + 两足底）；头部 3.0mm 间距、足底 3.2mm；CoP 亚间距插值精度 0.3–0.5mm，12×12 对足底 CoP 与头部抚摸方向判定均足够
- 前端：STM32G030（ZPM 零电位法，12 GPIO 推挽驱行 + 74HC4067 列 mux + 跨阻放大 + 内部 ADC，约 12×15mm，0.15–0.3ms/帧）
- 集线：STM32G431 **skin_hub，单一 Dynamixel 从机 ID 201**；寄存器映射：addr 128–175 = 4×12B 特征包，192+ = 分页全帧；robotd 每 tick sync_read 扩至 17 设备，总线 tick 占用升至约 33%（可接受）
- 供电/重量：HAT 5V + XC6206P332 LDO 出 3.3V，整机 +0.4W；结构+线束 +30g（3.8%）
- 机械：头部 PU 胶贴合 + FPC 经颈部两侧 **Ω 形服务环**进腔体（避开摄像头/ToF，过线孔加护线圈）；足底五层三明治（TPU 底片→硅胶扩散层→FPC 阵列→凹点刚性支撑→足体，M2 螺钉，脚踝 U 形弯套波纹管）
- 必要代价：+30g 质量/惯量需 **MJCF 参数回填 + 策略再训练**（观测向量 61→85 维）

## 3. 软件架构：robotd 唯一总线主机 + tactiled 解耦

**结论**：不改动现有 Rust 运行时原则下，新增一个低优先级守护进程即可，分两阶段落地把风险降到最低。

- `robotd`（改动最小化）：仍是总线唯一主站；仿 `model.rs` 注册 ID 200 的方式注册 201；皮肤特征与舵机状态**同帧对齐**（对 RL 训练价值极大）
- `tactiled`（新增）：不碰总线，经 JSON-RPC 从 robotd 订阅；负责热图重构、CoP 历史、接触事件判定、标定管理；优先级低于 robotd；全帧录制/诊断流量低频发起，永不进 50Hz 环
- **阶段一（零侵入）**：前端挂 HAT Stemma I2C（与 ToF 共总线），tactiled 独立跑通——不改 robotd 一行代码
- **阶段二（主链路切换）**：切到总线 ID 201，robotd 最小补丁，特征同帧入环
- 关键原则：**robotd 始终是唯一总线主机，tactiled 永不直接占用 UART2**

## 4. 商业分析：鸭子能卖多少、能留多久？

**结论**：硬件本身是约 $5 亿的小众市场（CAGR 约 7%），真正的价值在 Hugging Face 生态漏斗；端侧算力只够"反射层"，留存取决于 app/策略生态。

- 订单：$399 首发，首日预售 >$260 万（约 6,500 台，Thomas Wolf X 帖，经 Business Insider），交期 backlog 4–6 个月；对照 Reachy Mini 首年约 1 万台、价格从 $299 涨到 $399
- 生态事件：HF 于 2025-04 收购 Pollen；有 NVIDIA 拟 $129 亿收购 HF 的传闻（截至 2026-08 未证实）
- 算力边界（RK3566 NPU 实测）：YOLOv8n INT8 34fps；zipformer 流式 ASR RTF 0.196（可实时）；whisper_base RTF 1.178（不可实时）；1GB RAM 跑不了 LLM——**"反射在端侧，大脑在云/手机"**
- 喜新厌旧周期：学术共识 **2 周–2 个月**；留存靠订阅与生态——Anki（无经常性收入，倒闭）vs LOVOT（$65/月订阅，3 年留存 90%+）/ Aibo（$300/年云服务）

## 5. 答疑：Ω 形服务环是什么、买什么？

**结论**：服务环（service loop）不是商品，是布线工艺——活动关节旁留 Ω 形松弛弯吸收线缆长度变化，拉力不传到焊点/连接器。

- 鸭子颈部实操：FFC 长度 = 走线路径 + 两侧各留 20–30mm；弯折半径 ≥5mm；环的两个"脚"用背胶线夹 + 活结微型扎带固定在不动侧，环体悬空；装完手动全程转 ±170° 验证环体不被拉直
- 采购清单（搜索词）：FFC/FPC 软排线 0.5mm 间距（6–12 芯）、自粘式扎带固定座、微型尼龙扎带 2.5×100、PA 波纹管内径 5–7mm（足底防磨段）
