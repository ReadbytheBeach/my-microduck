# Session 02 · MicroDuck 视频驱动舞蹈 V1–V4 两日进展

> 主题：从单段人类舞蹈视频到 MicroDuck 强化学习策略，以及平地、坡地和硬质多材质地面的跨仿真验收
> 实验日期：2026-10-17 至 2026-10-18
> 实验项目：`microduck-ros2-isaac`
> 本文定位：结果与方法归档，不包含账号、密码、大型视频或 checkpoint 文件

---

## 1. 两日结论

已完成“人类舞蹈短视频 → 2D/3D 人体姿态 → MicroDuck 重定向 → mjlab PPO → ONNX → Isaac 交叉验收”的完整链路，并依次完成：

- **V1**：跑通端到端平地基线；
- **V2**：优化参考轨迹、摆动脚离地间隙和足部接触奖励；
- **V3**：加入 0–4° 坡度、随机坡向、0–5 mm 粗糙度和普通摩擦随机化；
- **V4 阶段 1**：加入普通地面、大理石和木地板的硬地面材质随机化。

核心结论不是“所有版本都越来越好”，而是：

1. V2 的轨迹与接触设计确实显著改善了跨仿真动作幅度和原地稳定性。
2. V3 在小坡度下保持了较高动作幅度，但 4° 漂移和训练倾倒仍需优化。
3. V4 阶段 1 没有缩小动作，但根部位移明显增大；所有 4° 组合位移都超过 0.25 m，**跨材质鲁棒性目标未通过**。
4. 目前只有固定种子、单环境的工程回放，没有多种子统计结论，也没有真机安全验证。

## 2. 实际技术链路

```text
白背景工作室女性舞蹈视频（原视频第 6–10 秒）
→ RTMPose Halpe-26 2D 姿态
→ MotionBERT-Lite H36M-17 时序 3D 姿态
→ MicroDuck 语义重定向、关节限位、支撑与摆动约束
→ duck_motion.npz
→ mjlab clip 任务 PPO
→ 烘焙观测归一化的 ONNX
→ Isaac 固定场景回放、视频、trace 和幅度分析
```

补充边界：

- 本链路**不依赖 AMASS、SMPL 或 GVHMR**，这些工具或数据集没有参与实际训练。
- `duck_motion.npz` 是参考动作容器，包含 fps、时长、关节名、14 关节绝对弧度、根高和双脚接触标签。
- actor 始终保持 61D 输入和 14D 关节位置输出，便于不同策略共用运行时契约。
- 舞蹈相位使用 `[cos(2πφ), sin(2πφ), 0]`，V2 之后轨迹周期为 4.9666667 秒。
- 导出统一走 `scripts/export.py`，避免遗漏观测归一化。

## 3. 版本目标与结果对照

| 版本 | 核心目标 | 主要策略变化 | 实测结论 |
|---|---|---|---|
| V1 | 验证完整视频舞蹈链路 | 初版重定向轨迹 + 平地 PPO | 跑通，但动作幅度和接触质量不足 |
| V2 | 提高动作清晰度与接触一致性 | clearance、支撑脚约束、鸭子接触标签重建、0.1 秒容差 | 幅度和原地稳定性显著优于 V1 |
| V3 | 适应坡度与轻微粗糙地形 | 复用 V2 轨迹，从 V2 warm-start，加入地形随机化 | 小坡度表现较好，4° 漂移与倾倒仍明显 |
| V4 阶段 1 | 适应普通/大理石/木质硬地面 | 从 V3 warm-start，加入材质比例和摩擦随机化 | 动作幅度维持或放大，但位移未达标 |

### 3.1 V1：端到端平地基线

- 2D 姿态：120/120 帧均检测到同一人物，无插值和多人轨迹。
- 3D 姿态：120×17×3，无 NaN。
- 鸭子参考轨迹：149 帧、30 fps、约 4.9667 秒，无关节越限。
- 完成 1000 轮训练、ONNX 推理和 32 秒 Isaac 回放。
- 最终训练指标：`dance_pose_track=3.3905/4.0`，`dance_feet_schedule=1.1977/2.0`。
- Isaac 中位幅度比：0.2216；平均根部平面位移约 0.02977 m。

**判断**：基线成立，但不作为高质量舞蹈验收通过。

### 3.2 V2：轨迹与接触奖励优化

主要改动：

- 摆动脚采用单边 15 mm clearance 目标，避免“接触标签说摆动、实际脚底未抬起”。
- 同时约束支撑脚高度和脚踝方向，减少鞋底倾斜和边缘穿地。
- 根据鸭子实际脚底轨迹，以 4/8 mm 迟滞阈值重建 `foot_contact`。
- 接触奖励增加 0.1 秒时间容差，容忍执行器响应延迟。
- HOME 循环过渡同时满足时长与最大关节速率约束。

结果：

- 左脚/右脚摆动平均 clearance：约 9.98 mm / 17.40 mm。
- `dance_pose_track=3.4271`，`dance_feet_schedule=1.2894`。
- Isaac 中位幅度比：0.2216 → **0.6301**。
- 平均根部平面位移：0.02977 m → **0.01289 m**。
- 并非所有指标都改善，例如 `head_yaw` 幅度比由 0.9103 降至 0.8455。

**判断**：轨迹本身和奖励目标的一致性，比单纯增加训练轮数更关键。

### 3.3 V3：坡度与轻微粗糙地形

训练配置：

- 任务：`Mjlab-DanceClip-Slope-MicroDuck`。
- 从 V2 `model_999.pt` warm-start，继续使用 V2 `duck_motion.npz`。
- 坡度 0–4°，坡向 0–360° 随机，粗糙度 0–5 mm，摩擦 0.8–1.2。
- mjlab 使用真实 hfield；Isaac 使用细分封闭网格，不通过旋转机器人伪造坡度。
- 1000 轮训练后：`dance_pose_track=3.1671`，`dance_feet_schedule=1.2112`，`fell_over=0.375`，`nan_state=0`。

最终 Isaac 验收：

| 场景 | 中位幅度比 | 平均根部位移 |
|---|---:|---:|
| 0° | 0.9018 | 0.00089 m |
| 2° | 0.8828 | 0.00835 m |
| 4° | 0.8248 | 0.14462 m |
| 4°、90° 坡向、5 mm 粗糙度 | 0.7747 | 0.03309 m |

测试：mjlab 地形与训练配置 18 项、视觉 8 项、Isaac 地形 3 项通过。

**判断**：动作幅度较 V2 提升，但高坡度稳定性和右侧膝/踝执行仍需改进。

## 4. V4 阶段 1：硬质地面材质随机化

### 4.1 配置与实验管理

三种硬地面：

- 普通地面：50%，摩擦 0.8–1.2，粗糙度 0–5 mm；
- 大理石：20%，摩擦 0.45–0.70，粗糙度 0；
- 木地板：30%，摩擦 0.45–0.75，粗糙度 0–0.5 mm；
- 机器人脚部摩擦保持 0.8–1.2，避免脚和地面同时变化而难以归因。

新任务为 `Mjlab-DanceClip-HardFloor-MicroDuck`，复用 V3 地形类，以三个命名 sub-terrain 和 `proportion` 表达材质比例。

  - `dance_feet_schedule=1.3288`；

## 5. 两天形成的关键工程经验

- **轨迹与奖励先于训练轮数**：V2 的主要收益来自可行参考轨迹、鸭子自身接触标签和执行器容差。
- **clearance 是摆动脚离地余量**：不是越大越好；过小会刮地或穿地，过大可能造成动作夸张和单支撑不稳定。
- **warm-start 不等于 resume**：跨任务加载时需要重置学习计数；同任务续训则保留计数和优化器状态。实际 checkpoint 编号应以文件为准，R02 最终是 `model_998.pt`。
- **坡度必须作用于真实地形**：不能通过旋转机器人或相机伪造。Isaac 粗糙地面还需细分顶面，并同步映射侧壁顶点，避免“只有四角噪声”或悬空侧壁。
- **Isaac 回放必须保留 `--reset-root-height 0.12`**：否则当前配置会在第一步触发 `low_root`，造成连续 reset。
- **第 999 步重置不是跌倒**：当前环境 20 秒 episode 在 50 Hz 下正常超时，幅度分析会剔除其附近帧。
- **动作幅度不是唯一目标**：V4 幅度大于 1 同时伴随大位移，说明补偿动作可能过强；必须同时看根部位移、足部接触、滑动和视频。
- **实验过程需要可追溯**：每个实验轮次都记录假设、代码差异、版本、配置、预算和结果，失败结果同样保留。

## 7. 下一步建议

1. 对比 R01 `model_499.pt` 与 R02 早期/最终 checkpoint 的同场景回放，判断 4° 微调是否产生过度补偿。
2. 增加支撑脚世界轨迹、接触力、实际接触标签和脚底滑动统计，再决定奖励调整方向。
3. 先修复普通地面和 4° 位移，再考虑水渍、地毯、沙地等更复杂材质。
4. 对关键场景使用未见种子、不同坡向和多组摩擦做统计验收，而不是只保留单条视频。
5. 在完成跨仿真、长时运行、执行器饱和和安全限位检查前，不把当前策略用于真机动作验证。
