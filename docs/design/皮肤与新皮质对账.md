## 0. 一页摘要

鸭子当前的不对称：**写入端强（15 舵机、50Hz 控制环），回读端弱（IMU + 关节编码器，几乎全是自感知）**——像一个只有运动皮质、几乎没有躯体感觉皮质的动物：向世界写动作，读不到世界的回信。皮肤（4×12×12）补上回读端，其价值按五次突破逐层定位：

- **转向层**：皮肤是鸭子第一个机身原生的效价源——超压=坏、抚摸=好、滑移=恐惧原型。效价不再是训练期遗留在权重里的 ghosts，而是机身实时发行；
- **模拟层**：触觉是 L1 世界模型信噪比最高的「真值通道」——生成模型可以幻觉图像，但世界无法伪造抵抗；且足底触觉流只有结合动作指令（传出副本）才可预测，皮肤因此**强迫世界模型长出自我模型**；
- **组织原则**：头/脚两块皮肤是两个不同器官，按 homunculus 原则分通路处理——脚底走「预测-抵消」，头部走「事件-回放」。

## 1. 五次突破定位：鸭子当前阶段体检

| 突破 | 鸭子现状 | 评级 |
|---|---|---|
| ① 转向 | L0 robotd 50Hz 反射（PPO）；奖励是训练时人给的，机身没有"自己的好坏" | ⚠️ 有反射，**无效价** |
| ② 强化 | Isaac Lab PPO 训练，ONNX 板载推理 | ✅ 已解决（但 δ 只活在训练期，上机后是冻结的习惯） |

| ⑤ 语言 | L3 云端 LLM | 🔶 外挂（"离体语言皮层"） |

**结论：鸭子相当于站在新皮质诞生前夜的脊椎动物。皮肤是推动它过这个夜的关键器官——因为它同时给转向层补效价、给模拟层补流量。**

## 2. 三条机制：皮肤如何帮鸭子"理解"物理世界

### 2.1 皮肤 = 抵抗性的专属通道（世界四签名中最硬的一个）

视觉提供一致性，**抵抗性**（世界推回来的力）只有触觉能给。摄像头看到"地上好像有东西"，足底 144 点感到"它真的在推我"。世界可以骗过生成模型的图像预测，但无法伪造抵抗。因此触觉是所有传感通道里的真值通道——部署方案中 CoP 突变触发防滑/防跌，本质上是**世界的否决权第一次进入控制环**。

### 2.2 皮肤 = 传出副本的对账单（自我/世界边界的产地）

再传入原则：必须区分"感觉变化是我自己造成的"还是"世界造成的"。鸭子自己的脚步声可预测（L1 知道 a_t，能预测足底压力波形），被推倒则不可预测。**装上皮肤后，L1 被迫学出自我模型**——足底触觉流只有结合动作指令才可预测：预期中的落地压力被减去（reafference cancellation），残差才是"世界对我做的事"。这个减法是原初自我的工程种子：**自我与世界的边界在触觉残差里长出来，不是声明出来的**。

### 2.3 皮肤 = 效价的物理接地（鸭子第一笔"自己的账"）

效价不是标签，是身体状态的直接读数。皮肤给鸭子三个机身原生的效价原型：**足底超压=疼痛原型、被摸头=社交奖励原型、滑移征兆=恐惧原型**。这是转向突破的补课。配套保险丝（Session 01 原则）：效价进在线学习环必须衰减+封顶，不得压倒温度/电量生存奖励——否则鸭子学会"讨摸"而忘记充电。

## 3. 大脑织法：五条设计原则（全部从书里来）

1. **L0：触觉反射走脊髓路线，不等大脑。** 缩足/防滑/倒地保护必须在 50Hz 环内硬反射（方案已如此）。补充：每个接触事件打 ±效价比特——价值发行方的第一枚硬币。
2. **L1：homunculus 原则——按信息密度分配，不按身体大小。** 头/脚是两个器官：**脚底=物理器官**（100Hz、周期性、大半可预测抵消 → 低 surprise 权重，常态沉入无意识；意识是残差显示器）；**头部=社会器官**（稀疏、事件驱动、密度极高 → 每次抚摸直接进惊奇事件簿、夜间优先回放）。别让均匀的 85 维 obs 把这条原则平均掉。
3. **把"真碰"写进 wake-sleep 的确认端。** L2 夜里梦出的策略，白天放量后**触觉残差是最便宜的确认信号**——梦里的世界不会推你，真世界会（梦只用于筛选，确认必须真碰世界）。
4. **效价封顶先行**（见 §2.3），实机调衰减曲线与上限。
5. **最远的一步：被抚摸是鸭子遇到的第一个"他者的行为"。** 摸头的手 = 另一个智能体的动作；头部皮肤+摄像头联合建模"那只手"，是鸭子世界模型里第一个他者模型的种子。心智化的第一个训练样本，可能真的从一次摸头开始。

## 4. 与既有设计的接口（增量，无推翻）

| 项 | 落地方式 |
|---|---|
| 85 维 obs | 不变；建议 L1 编码器对足底/头部通道分设 surprise 权重（§3-2） |
| 事件簿 | 头部抚摸事件默认高优先级标签（复用 v1.1 开放问题 #5 的 surprise 加权回放机制，零新增通路） |
| tactiled | 增加 ±效价比特与"自我造成/外界造成"标志位（可由 robotd 同帧动作指令做一级判定，残差留给 L1） |
| 政策通道 | 不变；触觉相关策略更新走既有验签 + shadow mode |

## 5. 开放问题

1. 足底 reafference cancellation 的显式程度：交给 L1 隐式学，还是 tactiled 里先做一级显式对消（用同帧动作指令）？前者省工程、后者省样本——待阶段一基线数据决定；
2. 抚摸奖励若进在线学习，封顶值与衰减曲线的实机调参方案；
3. "那只手"的他者模型：头部皮肤事件是否值得联动摄像头抓帧入事件簿（隐私分级见 v1 §8-3，默认只存低维特征）。
